# Formulário de acesso ao cronograma

Este projeto é uma página HTML simples com:

- validação de nome, cidade e telefone
- botão de envio com loading
- mensagem de sucesso
- salvamento dos dados no `localStorage`
- abertura do PDF em uma nova aba

## Como abrir

1. Abra o arquivo `index.html` no navegador.
2. Preencha os campos.
3. Clique em "Enviar".

Se quiser, também posso deixar esse projeto pronto para publicar no GitHub Pages ou em um servidor web.
